# healthusersguide.com

Companion site for *Health: A User's Guide* (Eric Silver). Public material only: the front page, letters and chatbot prompts written for the web (send.html, prompts.html and send/, generated from site_copy.py by build_send.py in the book repo), who to call by state, a corrections log, and a contact form. The manuscript is not here and never will be.
